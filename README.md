# Pixelboard

дашборд для аналитики пиксель баттла [@exterapixelbattle_bot](https://t.me/exterapixelbattle_bot)

## что внутри

- `pxboard.py` — сервер и страница: поле 512×512, дельты, тайлы, кланы, лента постановок, зум, миникарта, экспорт.
- `pxkeep.py` — супервизор: сам обновляет токен и перезапускает `pxboard`.

## запуск

```
python pxboard.py
```
запускается на порту 8808

полезные ключи:

```
python pxboard.py --port 9000        # другой порт
python pxboard.py --host 0.0.0.0     # доступ из локальной сети
python pxboard.py --token <bearer>   # кланы и топ игроков
```

без токена поле и метрики работают, панели «кланы» и «топ игроков» пустые.

## куда вставлять токен

токен — это `Bearer` из `/api/auth`, живёт около суток.

способ 1, аргумент:

```
python pxboard.py --token L6xcJWu28x...
```

способ 2, переменная окружения (токен не виден в списке процессов):

windows, cmd:

```
set PX_TOKEN=L6xcJWu28x...
python pxboard.py
```

windows, powershell:

```
$env:PX_TOKEN = "L6xcJWu28x..."
python pxboard.py
```

linux, macos:

```
PX_TOKEN=L6xcJWu28x... python pxboard.py
```

переменная читается только в `pxboard.py`, остальным скриптам токен не нужен.

## парольная фраза для смены токена

по умолчанию эндпоинт `/token` закрыт: без фразы поменять токен нельзя.

```
python pxboard.py --set-pass
```

спросит фразу дважды и запишет в `config.json` только pbkdf2-хеш с солью, 240 000 итераций. самой фразы в файле нет, восстановить её нельзя. `config.json` в `.gitignore`.

как закрыто:

- без верной фразы `403 bad_pass`, после пяти неудач — `429` на пять минут;
- запросы с чужим `Origin` отбиваются, чтобы сторонняя страница не поменяла токен через твой браузер;
- в консоль, логи и аргументы процесса фраза не пишется, сравнение через `hmac.compare_digest`.

кнопка `заменить` в панели «Токен» спрашивает фразу и значение, отправляет их на локальный сервер.

## что показывает

- поле и слои: дельты, тайлы, границы, горячие точки, сетка
- метрики: заполнение, энтропия, границы, прирост, прогноз, z-score, турбулентность, рисунки, свободный блок, дубли тайлов
- кланы: пиксели, клетки и участники из `/api/top`
- топ игроков: первые 15 строк рейтинга
- лента постановок в реальном времени

## источники данных

- `/live/canvas.bin` — раскраска, шапка `PXC1`: 24 байта + 512×512 индексов палитры.
- `/api/cell?x=&y=` — автор, клан и время последней постановки, без авторизации.
- `/live/head.bin` — сегмент текущей секунды, `PXS1`: 40 байт + записи по 5 байт, живёт около 10 минут.
- `/api/top`, `/api/clans` — официальная статистика, нужен bearer.

## оговорки

`/api/cell` помнит только последнего автора клетки, историю перезаписи задним числом не восстановить.

`seq` в шапке снапшота — общее число постановок с начала ивента.
