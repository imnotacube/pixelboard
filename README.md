# pixelboard

локальный дашборд и сборщики данных для pixel.mk69.dev.

## что внутри

- `pxboard.py` — сервер и страница: поле 512×512, дельты, тайлы, кланы, авторы, возраст, лента постановок, зум, миникарта, экспорт.
- `pxsnap.py` — докачиваемый проход по `/api/cell` в базу `px.db`.
- `pxsample.py` — быстрая выборка авторского слоя, чтобы кланы и авторы появились сразу.
- `pxwatch.py` — живой сбор постановок через `/live/head.bin`.
- `pxkeep.py` — супервизор: сам обновляет токен и перезапускает `pxboard`.

## требования

- python 3.10 или новее
- сторонних пакетов нет, только стандартная библиотека
- windows, linux, macos — без разницы

## установка

```
git clone https://github.com/imnotacube/pixelboard.git
cd pixelboard
```

больше ничего ставить не надо.

## запуск

```
python pxboard.py
```

открыть `http://127.0.0.1:8808/`

полезные ключи:

```
python pxboard.py --port 9000        # другой порт
python pxboard.py --host 0.0.0.0     # доступ из локальной сети
python pxboard.py --token <bearer>   # официальные цифры кланов
python pxboard.py --db px.db         # путь к базе авторского слоя
```

без токена работает всё, кроме колонок «на поле», «покрытие», «пикселей» и «люди» в панели кланов — там будет оценка по выборке с префиксом `≈`.

## куда вставлять токен

токен — это `Bearer` из `/api/auth`, живёт около суток.

способ 1, аргумент:

```
python pxboard.py --token L6xcJWu28x...
```

способ 2, переменная окружения (токен не виден в списке процессов):

windows, cmd:

```
set PX_TOKEN=L6xcJWu28x...
python pxboard.py
```

windows, powershell:

```
$env:PX_TOKEN = "L6xcJWu28x..."
python pxboard.py
```

linux, macos:

```
PX_TOKEN=L6xcJWu28x... python pxboard.py
```

переменная читается только в `pxboard.py`, остальным скриптам токен не нужен.

## парольная фраза для смены токена

по умолчанию эндпоинт `/token` закрыт: без фразы поменять токен нельзя.

```
python pxboard.py --set-pass
```

спросит фразу дважды и запишет в `config.json` только pbkdf2-хеш с солью, 240 000 итераций. самой фразы в файле нет, восстановить её нельзя. `config.json` в `.gitignore`.

как закрыто:

- без верной фразы `403 bad_pass`, после пяти неудач — `429` на пять минут;
- запросы с чужим `Origin` отбиваются, чтобы сторонняя страница не поменяла токен через твой браузер;
- фраза уходит только на `127.0.0.1`, на сайт `pixel.mk69.dev` не попадает ни в каком виде;
- в консоль, логи и аргументы процесса фраза не пишется, сравнение через `hmac.compare_digest`.

кнопка `заменить` в панели «Токен» спрашивает фразу и значение, отправляет их на локальный сервер.

## автообновление токена

```
python pxkeep.py
```

класть строку `initdata` в файл `initdata.txt` рядом со скриптом. супервизор сам обменяет её на токен, запустит `pxboard.py` на порту 8808 и раз в минуту проверяет `/api/me`. на `401` — меняет токен и перезапускает сервер, на протухшую `initdata` — пишет в `pxkeep.log` и ждёт новую строку в файле.

## наполнение базы

дашборд читает авторский слой из `px.db`. три способа:

```
python pxsample.py --n 600 --delay 0.7     # выборка, пара минут
python pxsnap.py baseline --rps 1          # полный проход, долго, докачиваемый
python pxwatch.py watch                    # живой поток, пишет в events
```

выборка даёт кланы и авторов сразу, но с погрешностью. полный проход делает цифры точными: `python pxsnap.py dump --out field.jsonl` выгружает результат.

сервер сайта банит за параллельность, поэтому по умолчанию один поток и один запрос в секунду. больше двух потоков — риск получить отказ на полчаса.

## что показывает

- поле и слои: дельты, тайлы, границы, горячие точки, кланы, авторы, возраст, сетка
- метрики: заполнение, энтропия, границы, прирост, прогноз, z-score, турбулентность, рисунки, свободный блок, дубли тайлов
- кланы: официальные клетки и пиксели с сервера, доля поля, участники
- авторы и памятники из локальной базы
- лента постановок в реальном времени

## источники данных

- `/live/canvas.bin` — раскраска, шапка `PXC1`: 24 байта + 512×512 индексов палитры.
- `/api/cell?x=&y=` — автор, клан и время последней постановки, без авторизации.
- `/live/head.bin` — сегмент текущей секунды, `PXS1`: 40 байт + записи по 5 байт, живёт около 10 минут.
- `/api/top`, `/api/clans` — официальная статистика, нужен bearer.

## оговорки

`/api/cell` помнит только последнего автора клетки, историю перезаписи задним числом не восстановить.

`seq` в шапке снапшота — общее число постановок с начала ивента.
