# pixelboard

локальный дашборд и сборщики данных для pixel.mk69.dev.

## файлы

- `pxboard.py` — сервер и страница: поле 512×512, дельты, тайлы, кланы, авторы, возраст, лента событий, зум, миникарта, экспорт.
- `pxsnap.py` — проход по `/api/cell`, докачиваемая база `px.db`.
- `pxsample.py` — быстрая выборка авторского слоя.
- `pxwatch.py` — живой сбор постановок через `/live/head.bin`.

## запуск

```
python pxboard.py --port 8808 --token <bearer>
```

без токена работают все панели, кроме официальных цифр кланов.

## источники

- `/live/canvas.bin` — раскраска поля, шапка `PXC1`, 24 байта + 512×512 индексов палитры.
- `/api/cell?x=&y=` — автор, клан и время последней постановки, без авторизации.
- `/live/head.bin` — сегмент текущей секунды, события `x, y, color`, живёт около 10 минут.
- `/api/top`, `/api/clans` — официальная статистика, нужен bearer из `/api/auth`.

## заметки

`/api/auth` отбивает запросы с не-браузерным `user-agent` (`403 {"err":"client"}`), поэтому все запросы идут с мобильным ua.
